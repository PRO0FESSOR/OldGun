## Backend Setup

- NODE JS - Runtime enviournment 
- EXPRESS - Handling regular http requests
- NODE HTTP SERVER  - To connect socket connection with the server 
- SOCKET.IO - Bidirectional and low-latency communication
- NODEMON - Restarting application

- npm i nodemon
